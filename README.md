# The Shannon Operating System

A decision system distilled from the primary sources of Claude Shannon —
built source-first, then synthesized into a cited framework anyone can use.
Built November 2026. Source cutoff: November 25, 2026.

By Athan Tsokolas. Licensed under [CC BY 4.0](LICENSE).

## What this is

Shannon did not win because he possessed a secret formula. He built an
unusually coherent method for turning a messy domain into a solvable problem
— find the algebra that fits, reduce the problem to selection from a set,
measure the selection, prove what is possible in the limit, state what the
proof withholds, and build the smallest working version that tests the
theory. This repository is that method, written down:

- **10 principles** — from finding the algebra to never mistaking a
  reconstruction for a record ([executive-brief.md](executive-brief.md)).
- **A 10-step master decision sequence** with a one-page decision-record
  template, plus variants for communication, investing, building products,
  and AI assistants ([operating-framework.md](operating-framework.md),
  [decision-record.md](decision-record.md)).
- **A layered method** — selection, measure, limit, stated withholding,
  building, curiosity, credit, genealogy, concentration — in Shannon's own
  working order
  ([notes/shannon-core-framework.md](notes/shannon-core-framework.md)).
- **A cited chronological reference** — how the thinking evolved, where the
  theory stops, and where it breaks
  ([cited-reference.md](cited-reference.md)).
- **A methodology audit** — source grades, coverage, provenance limits, and
  the anti-hagiography controls that kept the study honest
  ([methodology-and-corpus.md](methodology-and-corpus.md)).

## What this is not

- **Not a quote book.** The synthesis is overwhelmingly original paraphrase
  and analysis. Do not optimize for famous quotations; optimize for repeated
  principles, changes across decades, the conditions under which advice
  applies, and disconfirming evidence.
- **Not the corpus.** The 53 primary and secondary sources behind this study
  are copyrighted material and are not distributed here. See
  [corpus-sources.md](corpus-sources.md) for how to rebuild the corpus
  yourself from public archives.
- **Not investment advice.** This is a method for making decisions, not a
  recommendation about any security. The investing record discussed here is
  a reconstruction from fragmentary records, not an audited track record.
- **Not a live corpus.** Nothing after November 25, 2026 is in it, and 3 of
  the 16 primary items could not be read (the 1940 thesis PDF, the 1951 maze
  paper, and the 1987 Omni interview).

## The quotation rule

The corpus grades every source family A–D by provenance (see
[methodology-and-corpus.md](methodology-and-corpus.md)):

- **Grade A or clean Grade B:** quotable, after checking the underlying text.
- **Grade C** (interviews as reprinted, biographies, obituaries): paraphrase;
  exact wording needs independent confirmation.
- **Grade D:** discovery only. No load-bearing quotation.

File availability does not imply quotation fitness.

## Rebuild the corpus (the 53 items)

[corpus-sources.md](corpus-sources.md) lists every item's public source URL,
grouped by collection, with the fetch method, grade, and read status for each
source family (including the unread 1940 thesis, the borrow-restricted 1951
maze paper, and the second-hand secondary books that need verification
against copies in hand). The method: download from the source, extract text,
read chronologically in bounded tranches, record principles, changes,
boundary conditions, and disconfirming evidence.
